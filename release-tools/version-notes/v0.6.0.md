# HYPERION v0.6.0

## Highlights

- MNEMO is a HYPERION-managed local WeChat sidecar. With a signed-in local Windows WeChat session, it writes immutable incremental batches while HYPERION is running without a GUI, directory grant, or manual key capture.
- HYPERION remains the sole authoritative archive owner. It deduplicates stable message IDs, resumes safely after interruption, and feeds changed conversations into the existing incremental analysis workflow.
- Readable conversation files use the contact remark first and nickname second for both folder and JSON name. Local avatar blobs are signature-checked, content-addressed, and kept in HYPERION storage.

## Privacy And Upgrade

MNEMO never transmits local key material, chat body, or avatar files. Existing file imports and archive segments remain compatible. Back up HYPERION runtime data and MNEMO's private directory together when preserving a restorable local setup.

## Verification

The release is gated by the MNEMO Python tests, HYPERION inbox/server tests, full regression tests, lint, build, and a live local `/api/mnemo/status` check.
