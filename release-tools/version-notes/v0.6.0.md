# THEIA v0.6.0

## Highlights

- MNEMO is a THEIA-managed local WeChat sidecar. After one local key capture for an authorized account, it writes immutable incremental batches while THEIA is running.
- THEIA remains the sole authoritative archive owner. It deduplicates stable message IDs, resumes safely after interruption, and feeds changed conversations into the existing incremental analysis workflow.
- Readable conversation files use the contact remark first and nickname second for both folder and JSON name. Local avatar blobs are signature-checked, content-addressed, and kept in THEIA storage.

## Privacy And Upgrade

MNEMO never transmits the captured key, chat body, or avatar files. Existing file imports and archive segments remain compatible. Back up THEIA runtime data and MNEMO's private directory together when preserving a restorable local setup.

## Verification

The release is gated by the MNEMO Python tests, THEIA inbox/server tests, full regression tests, lint, build, and a live local `/api/mnemo/status` check.
