# HYPERION v0.1.1

Windows x64 便携版发布。

## 首选产物

- Windows 便携版：`artifacts/HYPERION-0.1.1-portable.zip`
- 对应 Git 标签：`v0.1.1`

便携版自带 Electron 与 Node.js 运行时。解压后运行 `HYPERION.exe`，任务、设置、聊天归档和日志写入 `%APPDATA%\HYPERION`，不会写回发布目录。

本版本没有单独的源码 ZIP；源码以公开 Git 仓库的 `v0.1.1` 标签为准。

所有 ZIP 的实际 SHA-256 以父目录 `SHA256SUMS.txt` 和自动生成的 `INDEX.md` 为准。
