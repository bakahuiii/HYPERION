## 核心陈述

> “THEIA 不是一个管理生活的软件，也不是一个分析聊天记录的工具。它是一个长期研究同一个对象的实验，而这个对象始终只有一个——我自己。它试图以时间为维度，将记忆、行为、情绪、关系、决策与环境连接起来，不是为了预测未来，也不是为了评价对错，而是为了尽可能完整地回答一个贯穿我人生的问题：我是如何成为今天的我的，又正在成为怎样的人。”
>
> — GPT-5.5

这段话不是宣传文案，而是 THEIA 的产品定义、研究边界和长期架构北极星。现在以及未来的任务、聊天、人物、关系、地点、行程、情绪、记忆和环境模块，都是为了逐步建立一条可追溯、可修正、由用户拥有的个人时间线。

## 研究对象与时间尺度

THEIA 始终只研究一个主体：用户自己。其他人物、群体、学校、工作、地点和事件之所以进入系统，是因为它们构成了用户经历与变化的上下文，而不是因为系统要替这些人建立客观档案或作出评价。

系统必须同时容纳多个时间尺度：

- 当下：正在发生的任务、情绪、选择和环境；
- 阶段：数周或数月内形成的习惯、关系变化和决策路径；
- 生涯：跨年度的学习、生活、身份与价值变化；
- 回望：后来获得的新证据如何修正过去的理解。

“时间”不能只是一条消息的时间戳。它还包括信息源时间、事件发生时间、用户确认时间、模型推断时间、修订时间和结论失效时间。

## 认识论边界

THEIA 不把数据量等同于真相，也不把模型生成的流畅文字等同于理解。系统中的内容必须区分：

1. **原始观察**：聊天、图片、文件、地点、日程或用户主动记录的内容；
2. **结构化事实**：能够直接追溯到原始观察、且明确主体与时间的陈述；
3. **模型推断**：由多条证据支持但仍可能错误的模式、倾向或解释；
4. **用户反思**：用户对自身经历的解释、修正和保留意见；
5. **行动选择**：用户决定接下来做什么，而不是系统替用户作出的裁决。

任何推断都必须能够回到证据，显示不确定性，并允许被新信息覆盖。系统宁可保留空白，也不应为了让人物卡、时间线或建议显得完整而编造连接。

## 设计原则

### 1. 纵向优先

单个瞬间很少足以描述一个人。优先展示变化、重复、持续、转折与例外，而不是从一句话生成稳定人格标签。

### 2. 来源优先

每个重要结论都应保留平台、会话、发言人、方向、原文引用和时间。来源不是调试信息，而是用户理解和纠错的核心界面。

### 3. 主体清晰

“你”“对方”“群成员”和系统推断必须严格区分。不能把对方的邀请、喜好或决定写成用户自己的，也不能用昵称猜测发言方向。

### 4. 事实、推断与建议分层

事实回答“发生了什么”，推断回答“这些证据可能说明什么”，建议回答“可以考虑做什么”。三者不得混成一段貌似确定的叙事。

### 5. 不预测、不评分、不裁决

THEIA 可以帮助回顾模式和理解选择，但不预测命运，不给关系、人格或人生阶段打分，也不把模型建议包装成唯一正确答案。

### 6. 用户主权

数据默认保存在本地。用户决定导入什么、向哪个模型发送什么、保留什么、删除什么。删除、导出、迁移和回滚必须真实可用。

### 7. 可修正而非一次定论

人物刻画、关系理解和事件意义应随证据更新。系统需要保存修订来源和时间，而不是用最新文字静默覆盖历史理解。

### 8. 安静的技术

界面应帮助用户观察与回想，不用等级、经验值、专注度、情绪操控或无意义通知把自我研究变成新的绩效系统。

## 当前功能如何为目标搭桥

| 当前能力 | 长期作用 |
| --- | --- |
| 聊天归档与导入 | 建立带时间、主体和来源的原始观察层 |
| 候选任务与行程 | 从交流中找出需要行动或未来验证的开放环节 |
| 人物与关系 | 保存他人如何参与用户经历的上下文，不替他人下定论 |
| 地图与地点 | 把经历连接到现实环境与空间变化 |
| 任务图 | 展示当前开放问题之间的关系，不作为效率排行榜 |
| 模型提炼 | 协助压缩、关联和提出假设，但所有结果都需可追溯、可审核 |
| append-only 归档与迁移 | 让长期时间线能够增长、恢复和回看，不因版本升级丢失 |
| 日志与协议 | 使模型处理过程可复现，避免错误被隐藏在“AI 生成”背后 |

## 开发决策门槛

一个新功能进入核心产品前，至少应满足以下一项，并且不得违反其他原则：

- 连接此前分散的跨时间证据；
- 帮助区分事实、推断、反思和行动；
- 让用户更容易查看来源、修正理解或撤销变更；
- 让长期数据更可靠、安全、可迁移或可复现；
- 帮助呈现“变化是如何发生的”，而不仅是“现在是什么状态”。

如果一项功能只增加任务数量、画像文字、参与时长或视觉刺激，却不能改善长期自我理解，它不应成为核心优先级。

## 成功标准

THEIA 的成功不是生成了多少任务、读取了多少消息或写出了多长的人物画像。更有意义的标准是：

- 用户能否从结论回到具体经历；
- 系统能否承认不知道，并在新证据出现时修正；
- 多年后数据是否仍可读取、理解和迁移；
- 用户能否看见自己的延续、变化与矛盾，而不是只得到一个标签；
- 技术是否让记忆与反思更清晰，同时保留人的复杂性和决定权。
